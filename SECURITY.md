# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a vulnerability:

1. **Do not disclose it publicly** on GitHub issues, pull requests, or discussions.
2. Submit a report through **GitHub Private Vulnerability Reporting** via the Security tab.
3. Provide details of the vulnerability, steps to reproduce, and impact.
